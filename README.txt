# GARAGE 24 — сайт-визитка автосервиса

Готовый статический сайт на:
- HTML
- CSS
- JavaScript

## Запуск
Откройте `index.html` в браузере.

## Что заменить перед отправкой клиенту
1. GARAGE 24 → название компании.
2. Телефон и email.
3. Адрес и ссылку на карты.
4. Цены и список услуг.
5. Тексты отзывов.
6. Плейсхолдеры фотографий на реальные фотографии автосервиса.
7. Ссылки VK / Telegram / WhatsApp.
8. При необходимости подключить реальную отправку формы (например, Telegram Bot, email API или backend).

## Важно
Форма в этой демо-версии не отправляет данные на сервер. Она показывает уведомление в браузере.
